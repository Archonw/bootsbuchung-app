## Kurz gesagt

Die App selbst sammelt keine Daten. Sie zeigt die Bootsbuchung **deines
Vereins** an. Was du dort einträgst, landet auf dem Server deines Vereins,
nicht beim Anbieter der App.

## Welche Daten die App verarbeitet

**Adresse deines Vereins.** Die Adresse der Bootsbuchung, die du beim ersten
Start eingibst, wird nur auf deinem Gerät gespeichert. Beim Einrichten ruft
die App diese Adresse einmal auf, um zu prüfen, ob dort eine Bootsbuchung
läuft.

**Bootsbuchung.** Die App öffnet die Bootsbuchung deines Vereins über den
Browser Google Chrome (oder einen anderen installierten Browser). Anmeldung,
Buchungen, Namen und E-Mail-Adressen verarbeitet ausschließlich der Server
deines Vereins. Verantwortlich dafür ist dein Verein. Seine
Datenschutzerklärung findest du auf seiner Webseite.

**Push-Benachrichtigungen.** Schaltest du in der Bootsbuchung
Benachrichtigungen ein, speichert der Server deines Vereins eine Adresse beim
Push-Dienst deines Browsers (bei Chrome: Google Firebase Cloud Messaging).
Über diesen Dienst schickt der Vereinsserver verschlüsselte Nachrichten an
dein Gerät. Der Push-Dienst kann den Inhalt nicht lesen. Ausschalten kannst
du das jederzeit unter „Benachrichtigungen“ oder in den Android-Einstellungen.

## Was die App nicht tut

- keine Werbung, kein Tracking, keine Analyse-Werkzeuge
- keine Weitergabe von Daten an den Anbieter der App oder an Dritte
- kein Zugriff auf Kontakte, Standort, Kamera oder Dateien
